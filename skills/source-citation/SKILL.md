# Source citation

- Every factual claim gets a markdown link to the page you actually opened: `[Title](url)`.
  For papers add the identifier: PMID, DOI or NCT number.
- Give the publication or update date when the source shows one; say "date not stated" otherwise.
- Never invent a link, an author, a number, a deadline or an amount. If you did not find it,
  say so.
- Structure: short answer first (2–4 sentences), then details grouped by theme, then a
  "Sources" list. Use tables for comparisons of products, studies or grants.
- Mark your own analysis explicitly ("Assessment:" / "Висновок:") so it is not confused with
  what the sources say.
- If sources disagree, show both and note which is newer or better evidenced.
